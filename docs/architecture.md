# BrainAgentSystem 架构文档

## 系统概述

BrainAgentSystem 是一个2047节点的大脑仿真Agent系统，采用满二叉树拓扑结构组织。

## 核心组件

### 数据类型层
- Tensor: 多维张量 (NCHW)
- StateVector: 状态向量
- Signal: 标量信号
- SpikeTrain: 脉冲序列

### 节点层
- BrainNode: 抽象基类
- 15个手动实现节点 (L00-L03)
- 2032个生成节点 (L04-L10)

### 通信层
- ASYNC_PUSH: 异步推送
- SYNC_CALL: 同步调用
- PUB_SUB: 发布订阅

### 调度层
- FrequencyScheduler: 多频率调度器
- 快循环 (5ms): 感觉通路
- 中循环 (20ms): 运动/记忆
- 慢循环 (100ms): 调节系统
